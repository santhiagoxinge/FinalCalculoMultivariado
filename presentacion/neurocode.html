Paraboloide convexo: un único mínimo, y es global.

∇S = 0 da un punto crítico: mínimo, máximo o silla. Lo decide la curvatura (segundas derivadas, H). det H > 0 y Saa > 0 ⇒ S es convexa (forma de taza, curva hacia arriba) ⇒ mínimo; si fuera cóncava sería máximo. Mínimo local = el más bajo de su alrededor; global = el más bajo de todos. H no depende de a ni b, así que S es convexa en todo el plano: no hay otro mínimo, el local es el global.

Interpretación geométrica

Un valle con un solo fondo

En el mínimo el plano tangente es horizontal. La bolita sigue −∇S: perpendicular a las elipses, siempre hacia el fondo.

Cómo se dibujó: una cuadrícula de 140 × 140 rectas (a, b) alrededor del óptimo; para cada una calculamos S con los 595 datos, y la altura z es ese error. Qué superficie es: un paraboloide elíptico (S es de grado 2 en a y b), convexo: una taza con un solo fondo, el mínimo global. Curvas de nivel = rectas con el mismo error; −∇S apunta cuesta abajo, perpendicular a ellas.

¿Por qué las elipses se inclinan?

∂2S∂a∂b = 2Σx = 107 100 ≠ 0

a y b están acoplados: subir la pendiente obliga a bajar el intercepto.

x − 90°  ⇒  Σ(x − 90) = 0  ⇒  Sab = 0

Al centrar, las elipses se enderezan. Mismo a*; el intercepto pasa a ser ȳ = 930.33 ms.

Sab mide cómo se acoplan a y b: si sube la pendiente, el intercepto debe bajar para seguir pasando por el centro (90°, 930 ms). Restando 90° a x, Sab = 0 y las elipses quedan derechas.

Trazas y secciones transversales11

Cada corte por el óptimo es una parábola

Fija b = b* y mueve a (o al revés): una parábola con vértice en el óptimo.

Traza: cortar la superficie fijando una variable (b = b*). Queda una parábola que abre hacia arriba (convexa), con el vértice justo en a*: ahí la pendiente de la tangente es 0 y es un mínimo.

Sin iteraciones

No hay que “buscar” el mínimo: la fórmula cerrada lo da exacto en un paso.

Sx, Sy, Sxx, Sxy = Σx, Σy, Σx², Σxy, acumuladas en un solo recorrido: O(n). No hay iteraciones: la fórmula que sale de ∇S = 0 da el mínimo exacto.

def fit(x, y):    n = len(x)    sx, sy = x.sum(), y.sum()    sxx, sxy = (x * x).sum(), (x * y).sum()    d = n * sxx - sx**2    a = (n * sxy - sx * sy) / d    b = (sy - a * sx) / n    return dict(n=n, sx=sx, sy=sy, sxx=sxx,                sxy=sxy, d=d, a=a, b=b)

3Σx, Σy x e y son vectores de NumPy
4Σx2, Σxy x * y multiplica elemento a elemento
5D0 = nΣx2 − (Σx)2
6a* = (nΣxy − ΣxΣy) / D0
7b* = (Σy − a*Σx) / n

No usa ninguna función de regresión: solo sumas, productos y una división. NumPy y SciPy aparecen después, únicamente para verificar.

x e y son vectores de 595 números. sx**2 = (Σx)², el total al cuadrado; sxx = Σx², la suma de los cuadrados. d = D₀ = nΣx² − (Σx)².
